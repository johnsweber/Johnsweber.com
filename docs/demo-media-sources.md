# Demo media sources

Demo mode uses twelve freely licensed example assets hosted by Wikimedia
Commons. The application stores only a private, user-owned library record and a
validated Commons redirect URL; it does not call a generation provider or copy
the source into the repository. Commons requires uploaded media to use a free
license and a free file format.
